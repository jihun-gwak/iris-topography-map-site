# Iris Topography Interactive Map

Interactive Korean iris topography guide built as a static HTML page.

## Files

- `index.html` - standalone interactive page
- `iris-topography-map.png` - map image used by the page

## Local Preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8765
```

Then visit `http://localhost:8765`.
